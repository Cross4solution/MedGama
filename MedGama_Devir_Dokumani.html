03 — Lokal Kurulum

Gereksinimler

AraçMinimum Versiyon
PHP8.4+
Composer2.x
PostgreSQL15+
Redis7+
Node.js18+

Backend Kurulum

cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8001

# Opsiyonel:
php artisan queue:work redis --sleep=3 --tries=3
php artisan reverb:start --host=0.0.0.0 --port=6001

Frontend Kurulum

# Proje kök dizininde
npm install --legacy-peer-deps
cp .env.example .env
# .env içinde: REACT_APP_API_BASE=http://127.0.0.1:8001/api
npm start
💡 İpucu: --legacy-peer-deps flag'i React 19 ile bazı paketlerin uyumluluk uyarılarını atlamak için gereklidir.

09 — Deploy Notları

Vercel (Frontend)

  • main branch'e push → otomatik deploy
  • Env: REACT_APP_API_BASE
  • SPA routing: vercel.json rewrites

Railway (Backend)

  • main branch'e push → Dockerfile build
  • Supervisor: nginx, php-fpm, queue, reverb, scheduler
  • Boot: artisan optimize + migrate

Railway'de Ayarlanması Gereken Env'ler

APP_ENV=production
APP_DEBUG=false
APP_KEY=base64:...
CORS_ALLOWED_ORIGINS=https://med-gama.vercel.app
FRONTEND_URL=https://med-gama.vercel.app
MAIL_MAILER=log
REVERB_APP_KEY=your-reverb-key
REVERB_APP_SECRET=your-reverb-secret
SANCTUM_STATEFUL_DOMAINS=med-gama.vercel.app
📌 Not: DATABASE_URL ve REDIS_URL Railway plugin'leri tarafından otomatik sağlanır. Manuel ayarlamaya gerek yok.

10 — Demo Modu

⚠️ Önemli: Şu an sistem MAIL_MAILER=log ile çalışıyor. Bu demek ki:
  • Kayıt olan kullanıcılar otomatik doğrulanır (email verification atlanır)
  • Gerçek mail gönderilmez, storage/logs/laravel.log dosyasına yazılır
  • Gerçek mail sunucusu bağlandığında .env'de MAIL_MAILER=smtp yapılması yeterli
  • Backend'de bu mantık app/Services/AuthService.php → $isDemoMail flag'i ile kontrol edilir
